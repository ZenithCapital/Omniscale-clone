## Common Mistakes & Fixes

1. **Under-specifying**: "character jumps" → add anticipation, squash-stretch, arc trajectory details
2. **Style conflicts**: Choose ONE primary style + optionally ONE accent
3. **No follow-through**: Add "hair lags 0.2s behind body, fingers settle last"
4. **Vague colors**: Use hex codes or specific named colors at stated saturation
5. **Missing timing**: Specify fps and duration for every key action
6. **Weak hook**: Open with ONE unmissable visual pop in first 0.5–1.5 seconds
